### 1. Dynamic Schedule Management
- **Classroom Organization:** Records entries using standardized block and room identifiers (e.g., B202).
- **Academic Tagging:** Supports specific flags for critical events such as examinations, laboratory sessions, and other extra tasks.

### 2. Context-Aware Budget Manager
- **Budget Profiles:** Offers customizable spending modes (`Save`, `Recommended`, `Social`) that adapt based on the student's needs.
- **Commute Tracking:** Calculates transportation costs dynamically using fixed-route lookup mappings (e.g., origin-to-campus routes and return fares for public transit or personal transport).
- **Academic Material Costs:** Automatically factors in recurring fixed expenses, including test paper fees ($0.10) and laboratory documentation ($0.0).
- **Daily Variables:** Accounts for meal plans, ask the user if they eat lunch at home or at college.
- **Exam-Week Lock:** Detects examination periods within the active schedule to prioritize budget-saving modes.

### 3. Campus Navigation
- **Sequential Routing:** Extracts destination blocks and room numbers directly from the student's schedule.
- **Route Selection:** Evaluates route efficiency, alternative corridors, and landmark checkpoints.
